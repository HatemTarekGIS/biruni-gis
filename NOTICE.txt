-------------------------------------------------------------------------------
The QGIS engine
-------------------------------------------------------------------------------
Biruni GIS runs on an unmodified build of QGIS 4.2.3 (https://qgis.org), as
packaged for Windows by the OSGeo4W project (https://trac.osgeo.org/osgeo4w/).
QGIS is licensed under the GNU GPL version 2 or later.

"QGIS" is a trademark of QGIS.org. Biruni GIS is an independent derivative
product; it is not the official QGIS release and is not endorsed by the QGIS
project.

Source code of the engine:
  QGIS ........ https://github.com/qgis/QGIS  (tag final-4_2_3)
  OSGeo4W ..... https://download.osgeo.org/osgeo4w/v2/  (source packages)
Biruni GIS will also provide the corresponding source code on request.
